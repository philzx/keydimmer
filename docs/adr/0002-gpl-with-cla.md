# GPL-3.0, with a CLA for outside contributions

KeyDimmer is licensed GPL-3.0 so anyone who ships a fork must keep it open. Paid features (open core: a closed Pro module or paid binaries) stay possible later only because the author holds the copyright to all of the code, so the first outside contribution requires signing a lightweight CLA (via CLA Assistant); without it, contributed GPL code would bind the author too and rule open core out. MIT code borrowed from Lunar or MonitorControl is compatible, provided its copyright notices are kept.
